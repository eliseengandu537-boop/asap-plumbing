# asap-plumbing

Vercel deployment uses `vercel.json`: no framework preset, `npm run build`,
and the static `dist` output directory. `server.cjs` is for local preview only.

ASAP Plumbing HTML website demo.

Open index.html directly, or run npm start and visit http://localhost:3000.

Run npm run check for JavaScript syntax checks. See README.txt for demo details.
