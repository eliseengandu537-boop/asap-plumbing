ASAP PLUMBING — CLIENT PRESENTATION

Open index.html in Chrome or Edge. No installation or build is required.
Keep index.html, styles.css, app.js and the assets folder together.

Optional local server: npm start, then visit http://localhost:3000
Syntax checks: npm run check

The layout follows the supplied Webild HVAC reference: blue and white,
photographic overlay hero, split about section, rounded service cards,
project photography, three-step process, FAQs and a contact section.

The assistant is an explicitly labelled, browser-only demonstration using
guided responses. A live AI assistant needs a secure server-side integration.
No API keys, real booking system or live availability are included.
Chat stays in memory and resets on reload. Nothing is sent automatically.

WhatsApp buttons use the business's published phone number, 065 191 8511.
Confirm that WhatsApp is enabled on this number before a public launch.
The enquiry form prepares a WhatsApp message for the visitor to review/send.
